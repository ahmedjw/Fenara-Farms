# Photos

Drop your farm photos into this folder using the exact filenames below. The
site picks them up automatically. Until a file is here, that slot shows a
labelled placeholder naming the shot, so nothing looks broken while you shoot.

JPG or WebP both work. Aim for the sizes given, then compress. Nothing here
needs to be larger than about 400KB.

## A note on shooting these

The whole site argues that this oil is grown rather than manufactured. Photos
that look like stock photography undercut that faster than anything in the
copy. Real light, real hands, real dirt.
